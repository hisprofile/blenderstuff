# TF2 Animations
TF2 animations are easy to add onto a character. Simply add an animation as an NLA strip onto a character.

https://github.com/user-attachments/assets/66f82691-01e8-44ca-8b14-e80f423070dd

Animations starting with "d." mean they are _delta_, or _additive_ animations. Their blending mode is required to be set to "Combine", and they require a non-delta animation beneath itself.

Animations can be sourced from this [Google Drive folder,](https://drive.google.com/open?id=1fxEiL8BHL3HpaFeJ0draoyjjNGNj5UQi&usp=drive_fs) which contain the complete animation pack of all mercenaries. Including workshop taunts.
